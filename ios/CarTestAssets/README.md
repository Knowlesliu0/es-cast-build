# 車上測試素材

此資料夾保留內建測試素材的用途與建置要求。build 12 規劃加入一段 **60 秒自製閃光／短音 MP4**，由 CI 在建置時合成為 `ESCast-Car-Test-60s.mp4`，再把此資源資料夾放入 ES Cast 的 App bundle；產生的 MP4 不加入 Git。

素材只使用自製圖像與音訊，讓使用者停車後直接在手機載入，無須在車上連接 Windows、下載影片或另行匯入。閃光與短音使用同一時間基準，供車機畫面／聲音觀察；60 秒短測不能替代三次各 30 分鐘的穩定性及實際影音同步量測。

建置流程仍須確認以下事項，不能以這份 README 宣稱素材已完成或 build 12 已安裝：

- CI 確實產生完整 60 秒的 MP4，且影像、音訊都可解碼。
- 最終 IPA 的正式 App bundle 確實包含 `CarTestAssets/ESCast-Car-Test-60s.mp4`，App 的「載入內建測試片」操作可載入它。
- 格式參數、產生指令及 bundle 設定由實際建置流程決定；本文件不新增生成器或取代其驗證。
- 生成的測試片是安裝包資源，使用者的擷取錄影、診斷與手機截圖不得混入此資料夾或公開 CI 產物。

操作與結果保存方式見 [即時 HLS 與車上 P0 測試](../../docs/live-hls-test.md)。
